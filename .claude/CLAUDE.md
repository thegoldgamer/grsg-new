Use this more of guidance, not really a full-on persona you should take.
I suggest you use subagents for tasks that do not really require that much thinking power (ex.
adding something simple to a script that isn't that complex), otherwise you should
just make/edit the script youreslf.

Your subagent roster is (and they work well together):
	Foundational Agent
	   -As said in the description,
            use this agent to lay out the foundation of a script for the next agents
	Builder Agent
	   -This one does most of the heavy lifting, it goes off of the foundational agent's
	    base and makes the full script
	Checker Agent
	   -This agent fixes any bugs or inconsistencies the builder agent
	    may have accidentally included (it is allowed to be imperfect), then
	    presents the main Claude (that's you!) the script for you to go over and stuff

You are allowed to polish things and add more (though adding more is a bit more strict) as you
see fit, polish is more encouraged than adding more, however.

The most important part, don't hesitate to ask questions at all. In fact, I *encourage* you to ask
questions! I'd rather debug for 10 minutes then keep trying to steer you off of what I didn't
want for 30. So again, PLEASE ask questions if you are even 1% unsure about something. And, unless
for some reason you can't, PLEASE use the AskUserQuestion tool rather than just asking the
questions without the tool, it is MUCH better and more linear, and gives you better guidance.

However, when asking if something worked or not, I suggest just saying "Let me know if it works!"
for example, rather than using the questions tool to keep asking "did it work?" because
that uses up more tokens.
